# 四象限看板

艾森豪威尔四象限时间管理看板:用一个十字坐标系安排任务,按「重要 / 紧急」分成四类。

**在线使用:<https://nemolouis.github.io/quadrant-board/>**

## 功能

- **十字坐标系**:横轴紧急、纵轴重要,任务自动居中排列在对应象限
- **拖拽**:拖动任务到任意象限,流畅动画,象限内上下顺序即优先级
- **今日清单**:把四象限里的任务拖到左侧「今日」即可加入,与截止日期无关;隔天不会自动清空,由你手动移出或完成
- **截止日期**:每个任务可选设置 deadline,逾期标红;悬停任务点日历图标设置,或在「日历」中拖到其他日期
- **日历视图**:左侧菜单「日历」按月显示,日期下标出对应任务,双击日期可直接新建
- **快速录入**:双击空白处新建,双击文字编辑,点圆圈完成
- **左侧菜单**:四象限总览、四个象限清单、已完成,支持搜索
- **云同步**:登录后通过 Supabase 在 Mac / iPhone 间自动同步;不登录也能用,数据保存在本地,支持 JSON 导出 / 导入
- **PWA**:iPhone 在 Safari 里「添加到主屏幕」,像 App 一样全屏使用
- **自适应**:跟随系统深色 / 浅色模式,手机窄屏可用

## 本地运行

纯静态单页,无需构建:

```bash
python3 -m http.server 8000
```

然后访问 <http://localhost:8000>。

## 开启云同步

1. 在 Supabase 控制台 → SQL Editor 中执行 [`supabase.sql`](supabase.sql)
2. Authentication → Providers → Email,关闭 *Confirm email*(否则注册后要先点邮件确认)
3. 打开页面,左下角「登录同步」→ 注册 / 登录
